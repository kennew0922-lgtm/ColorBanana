BASIC HTML TEMPLATE 【1分改造即配置テンプレ】
<span style="font-family: 'Helvetica Neue', Arial, sans-serif; font-weight: bold; font-size: 20px; color: #ff0000;"></span> "font-family" = 「フォントの種類指定（不要なら削除で全体を引き継ぎ）」
"font-weight" = 「太さ指定（boldで太字、normalで標準）」
"font-size" = 「文字のサイズ指定（pxやremなどで指定）」
"color" = 「文字の色指定（不要なら削除、透過も可能♪）」
<hr style="border: none; border-top: 1px solid #00e5ff80; width: 100%;"> "border-top" = 「腺の太さ指定」
"solid" = 「腺の色指定（16進数はフォトショのスポイトで抽出♪）（16進数の後ろの80は50％透過でこれが綺麗）
"width" = 「腺の長さ」
